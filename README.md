## 使用方式

### 原始 GitHub raw 链接

```
https://raw.githubusercontent.com/youlinduzhou/ofl-cn-fonts/main/fonts/字体文件名
```

### 国内镜像加速

```bash
# ghfast.top（推荐，国内访问最快）
https://ghfast.top/https://github.com/youlinduzhou/ofl-cn-fonts/raw/main/fonts/字体文件名

# gh-proxy.com（Cloudflare Workers 加速）
https://gh-proxy.com/https://github.com/youlinduzhou/ofl-cn-fonts/raw/main/fonts/字体文件名

# jgithub.xyz（国内直连镜像）
https://jgithub.xyz/youlinduzhou/ofl-cn-fonts/raw/main/fonts/字体文件名
```
